# CubicLauncher

Лёгкий лаунчер Minecraft: Java Edition в духе Modrinth App — **без рекламы, без телеметрии, без аккаунта в лаунчере**.
Моды ищутся и ставятся из **Modrinth** и **CurseForge**, обязательные зависимости подтягиваются сами.

## Запуск

Нужен [Node.js 20+](https://nodejs.org).

```bash
npm install
npm start
```

### Сборка .exe (Windows)

**Быстрый вариант, Node.js не нужен:** двойной клик по **`make-portable.bat`**. Скрипт скачает официальный Electron с GitHub,
проверит контрольную сумму и соберёт папку `dist-portable\CubicLauncher` с готовым `CubicLauncher.exe`.

**Установщик и однофайловый exe:**

Двойной клик по **`build-exe.bat`** — он сам выполнит `npm install` и `npm run dist`. В папке `dist/` появятся
`CubicLauncher-Setup-*.exe` (установщик) и `CubicLauncher-Portable-*.exe` (один файл без установки).
Либо загрузите проект на GitHub и запустите workflow **Build exe** — готовые файлы будут в Artifacts.
Файлы не подписаны цифровой подписью, поэтому SmartScreen покажет предупреждение («Подробнее» → «Всё равно запустить»).
Для macOS/Linux: `npm run dist` на соответствующей системе.
Проверка логики без сети: `npm test`.

## Что умеет

- Сборки (профили): своя папка с модами, мирами и настройками, версия Minecraft и память для каждой
- Загрузчики: **Fabric**, **Quilt**, Vanilla; **Forge** и **NeoForge** — экспериментально (см. ниже).
  Версию загрузчика можно задать вручную при создании сборки (пусто — последняя стабильная)
- Java ставится сама (официальные рантаймы Mojang, нужная версия под каждую сборку)
- **Моды, ресурспаки и шейдеры** из **Modrinth** и **CurseForge** с автофильтром по версии игры и загрузчику
- Установка вместе с обязательными зависимостями, проверка хэшей, включение/выключение/удаление
- **Выбор конкретной версии** мода или пака (кнопка «Версии»)
- **Проверка и установка обновлений** для всего, что поставлено через лаунчер (выключенные файлы остаются выключенными)
- **Модпаки**: импорт файлов `.mrpack` (Modrinth) и `.zip` (CurseForge), а также поиск и установка модпака из каталога
  одним нажатием — создаётся новая сборка с нужной версией игры, загрузчиком, модами и настройками
- Вход через аккаунт Microsoft (лицензионный Minecraft: Java Edition)
- Журнал игры внутри лаунчера

## Первая настройка

### Что работает без ключей
- Моды, ресурспаки, шейдеры и модпаки из **Modrinth** (там многие моды из CurseForge тоже есть).
- Любые файлы, скачанные вручную: страница сборки → **Добавить файлы**.

### Каталог CurseForge — нужен ключ (один раз)
CurseForge не отдаёт каталог без API-ключа, и это правило самого CurseForge: создать ключ за вас или вшить чужой нельзя.
Есть два пути:
1. **Для себя:** получите бесплатный ключ на <https://console.curseforge.com/> (API Keys) и вставьте его, когда лаунчер попросит
   (в «Обзоре» при выборе CurseForge или в «Настройках»). Хранится зашифрованным средствами ОС.
2. **Чтобы приложение вообще не спрашивало:** положите свой ключ в `src/main/builtin.json` (образец — `builtin.example.json`)
   или задайте переменную `CUBIC_CURSEFORGE_KEY` перед сборкой/запуском. Так же можно вшить `msClientId`.
   Ключ внутри приложения можно извлечь, поэтому такие сборки не раздавайте посторонним.

Если автор мода запретил скачивание сторонними программами (`allowModDistribution = false`), лаунчер **не обходит запрет**:
он откроет страницу файла на сайте CurseForge, и мод нужно скачать вручную в папку `mods` сборки.
То же касается модпаков CurseForge: такие файлы попадут в список «Не скачано» с ссылками на сайт.
Для импорта модпаков CurseForge ключ тоже нужен; модпаки Modrinth работают без ключей.

### Модпаки
«Библиотека» → **Импорт модпака…** (файл `.mrpack` или `.zip`) или **Найти модпак** (каталог Modrinth/CurseForge).
Для `.mrpack` скачивание разрешено только с хостов, которые допускает спецификация формата
(`cdn.modrinth.com`, `github.com`, `raw.githubusercontent.com`, `gitlab.com`); файлы для сервера пропускаются.
Если импорт не удался, недоделанная сборка удаляется.

### Вход через Microsoft
Лаунчер использует стандартный вход по коду устройства. Для него нужен свой **Client ID**:

1. В [Microsoft Entra / Azure](https://entra.microsoft.com) → App registrations → New registration.
   Тип учётных записей: *Personal Microsoft accounts only*.
2. Authentication → включите **Allow public client flows**.
3. Новым приложениям Mojang открывает доступ к Minecraft API по заявке (форма «Minecraft Services API app registration»,
   ссылка на неё есть в описании на wiki.vg — Microsoft Authentication Scheme). До одобрения вход будет завершаться ошибкой.
4. Вставьте Application (client) ID в **Настройки** (или вшейте его в `builtin.json`, см. выше).

Без одобренного Client ID вход невозможен, а значит, и запуск игры. Лаунчер не содержит офлайн-режима и не обходит проверку лицензии.

## Где лежат данные

Папка пользовательских данных приложения (Electron `userData`): `shared/` (версии, библиотеки, ресурсы — общие для всех сборок),
`instances/<id>/minecraft/` (игровая папка сборки), `runtimes/` (Java), `settings.json`, `accounts.json`.
Токены и ключ CurseForge хранятся зашифрованными.

## Безопасность

- Окно интерфейса изолировано (contextIsolation, sandbox, строгий CSP), наружу открываются только https-ссылки
- Имена файлов модов из сети проверяются, выход за пределы папки `mods` невозможен; zip-архивы защищены от zip-slip
- Все загрузки только по https, с проверкой sha1/sha512

## Честно о состоянии проекта

Проект написан и проверен **без доступа к реальным серверам Mojang, Modrinth, CurseForge и Microsoft**
(в среде разработки сеть была закрыта). Проверено автотестами (`npm test`: 26 сценариев ядра с подменой сети и поддельной Java + 13 сценариев интерфейса на имитации DOM):
правила Mojang, сборка аргументов запуска, наследование версий Fabric, поиск и установка модов/ресурспаков/шейдеров,
зависимости, выбор версии, обновления, импорт `.mrpack` и CurseForge-модпаков, цепочка входа Microsoft→Xbox→Minecraft,
сквозной запуск Vanilla и Fabric.

**Не проверено вживую** — возможны расхождения с реальными ответами серверов:
- реальный запуск игры и скачивание Java Mojang на вашей ОС
- **Forge и NeoForge** — запускаются через официальные установщики; для новых версий игры схема именования и аргументы могут отличаться
- вход через Microsoft (зависит от одобрения вашего Client ID)
- интерфейс в настоящем Electron: логика проверена на имитации DOM, а внешний вид — в обычном Chromium
  с подставным API; собственная панель окна с системными кнопками (`titleBarOverlay`) в живом Electron не видна никому
- реальные ответы каталогов для новых функций (ресурспаки, шейдеры, модпаки, выбор версии) — запросы собраны по
  документации API, но не сверялись с живыми серверами
- модпаки CurseForge, где часть модов запрещает сторонние загрузки, потребуют ручного скачивания этих файлов

Если что-то не работает, откройте вкладку **«Журнал»** сборки — там причина.

## Пока не реализовано

Экспорт собственной сборки в `.mrpack`, обновление самого модпака до новой версии (сейчас — установка заново как новая сборка),
выбор версии загрузчика из списка (сейчас — ручной ввод), шейдеры в виде папок (поддерживаются только `.zip`),
дедупликация модов, которые вы положили в папку вручную (лаунчер не знает их источник и не обновляет).
