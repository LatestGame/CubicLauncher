# CubicLauncher

Лёгкий лаунчер Minecraft: Java Edition в духе Modrinth App — **без рекламы, без телеметрии
Моды ищутся и ставятся из **Modrinth** и **CurseForge**, обязательные зависимости подтягиваются сами.
Ad-free Minecraft Java launcher: mods, modpacks, resource packs and shaders from Modrinth and CurseForge, Microsoft account sign-in.
